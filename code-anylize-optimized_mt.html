词法扫描 → 声明识别 → 嵌套关系 → 调用匹配。四个阶段都只处理 token 与语法结构，不解释函数体的语义。

分析边界

不推断运行时行为，不排序代码质量，不解释变量含义，不生成箭头，也不展开宏体。所有结论都停留在语法层面。
